# Simulation and Modeling – Assignment 1
**Topic:** Parameter Estimation - Offline Least Squares Estimation Method (LSE)  
**Course:** Simulation and Modeling of Dynamic Systems  

## 📘 Description
This project focuses on the **offline estimation of unknown parameters** of a dynamic system using the **Least Squares Estimation (LSE)** method.  

The system is a **linearized simple pendulum with input torque**, described by:

$$ mL^2 \ddot{q}(t) + c\dot{q}(t) + mgL q(t) = u(t) $$  

where:
- \( q(t) \) [rad]: pendulum angle  
- \( m \) [kg]: mass  
- \( L \) [m]: pendulum length  
- \( c \) [N·m·s]: damping coefficient  
- \( g \) [m/s²]: gravity acceleration  
- \( u(t) \) [N·m]: control input  

The goal is to estimate the unknown parameters \( m, L, c \) using LSE, compare the results with the true system response, and visualize the errors.

---

## ⚙️ Implementation
- **Language:** MATLAB  
- **Steps:**
  1. Formulate the system in **state-space form** \( \dot{x}(t) = Ax(t) + Bu(t) \).  
  2. Simulate the system response using an ODE solver with input \( u(t) = A_0 \sin(\omega t) \).  
  3. Apply **offline Least Squares Estimation** to estimate the parameters \( m, L, c \).  
  4. Compare estimated parameters with the true system.  
  5. Plot the results: \( q(t) \), estimated \( \hat{q}(t) \), and the error \( e_q(t) = q(t) - \hat{q}(t) \).
